## 對話摘要與開發歷程
================================================================================

### 階段 1: 需求分析與可行性研究
--------------------------------------------------------------------------------
- 用戶需求: 建立高雄捷運碳排放計算器
- 研究 TDX API 可用端點:
  * /v2/Rail/Metro/Station/KRTC (站點資料)
  * /v2/Rail/Metro/ODFare/KRTC (起迄站票價與里程)
- 確認碳排放係數: 高雄捷運 220 gCO₂e/人公里 (2023 官方數據)
- 比較指標: 開車 ~150 gCO₂e/km, 機車 ~88 gCO₂e/km
- 結論: 可行，利用 ODFare API 取得里程資料進行計算

### 階段 2: 核心功能開發
--------------------------------------------------------------------------------
建立檔案:
- carbon-calculator.js: 碳排放計算核心邏輯
  * TDX API 站點載入
  * ODFare 里程查詢
  * 碳排放計算 (距離 × 220 gCO₂e/km)
  * 與開車/機車比較
  * CSV 匯出功能

- carbon-app.js: 前端控制器
  * UI 互動處理
  * 站點選擇器
  * 計算結果顯示
  * 歷史記錄管理

### 階段 3: UI 更新
--------------------------------------------------------------------------------
修改檔案:
- index.html: 新增碳排放計算器 UI 區塊
- style.css: 新增樣式 (站點選擇器、結果卡片、比較徽章)

功能特色:
- 起站/迄站下拉選單
- 即時碳排放計算
- 與開車/機車比較 (顯示省碳量)
- 等效指標 (大樹吸收天數、手機充電次數)
- CSV 匯出功能

### 階段 4: 本地測試與故障排除
--------------------------------------------------------------------------------
遇到問題:
1. Vercel CLI 安裝問題 (npm cache 損壞)
2. node_modules 在雲端硬碟同步時損壞
3. API 500 錯誤 (axios 模組遺失)

解決方案:
- 建立 server-standalone.js (無外部依賴的獨立伺服器)
- 使用原生 Node.js http/https 模組
- 自定義環境變數載入器 (取代 dotenv)
- 完全避開 npm 依賴問題

### 階段 5: GitHub 發布
--------------------------------------------------------------------------------
操作步驟:
1. 更新 .gitignore (排除 .env, node_modules)
2. 修改 server-standalone.js 移除硬編碼憑證
3. 建立完整 README.md (含 Deploy to Vercel 按鈕)
4. Git commit 並 push 至 GitHub

Repository: https://github.com/klin1976/tdx-carbon-calculator

### 階段 6: Vercel 部署
--------------------------------------------------------------------------------
部署過程:
1. 使用 "Deploy to Vercel" 按鈕
2. 設定 Root Directory: tdx-sample-web
3. 設定環境變數: TDX_CLIENT_ID, TDX_CLIENT_SECRET
4. 完成部署

最終解決:

- 成功部署至: https://tdx-sample-web.vercel.app

### 階段 7: 生產環境優化
--------------------------------------------------------------------------------
需求: 正式環境只顯示碳排放計算器，隱藏開發工具

實作:
- 在 HTML 元素加入 dev-only class
- 加入 JavaScript 環境判斷邏輯:
  ```javascript
  const isLocalhost = window.location.hostname === 'localhost' || 
                     window.location.hostname === '127.0.0.1';
  if (!isLocalhost) {
      document.querySelectorAll('.dev-only').forEach(el => {
          el.style.display = 'none';
      });
  }
  ```

驗證結果:
- 正式環境: 僅顯示碳排放計算器 ✅
- localhost: 顯示所有開發工具 ✅
